## How I use these notes

1. Study a small topic and run the example.
2. Close the lesson and explain the idea in my own words.
3. Change the example and predict the result before running it.
4. Record important mistakes and unanswered questions.
5. In a later session, answer a review question without looking.

Keep complete exercises in their JavaScript files. Use these notes for short examples and explanations. Add links to exercise files when their paths are known.
